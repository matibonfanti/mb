The Great LLM Bottleneck and Memory

January 2026

home projects reading list

A note arguing that the binding constraint on AI's commercial usefulness is not raw model intelligence but effective context: the transformer's attention mechanism scales quadratically with sequence length and stores every token at full resolution, so it cannot compress the way a human reader does. More chips and more high-bandwidth memory do not remove this constraint, and agents and retrieval work around it rather than solving it. The piece sets out what that implies for the semiconductor memory trade under three architecture scenarios.
